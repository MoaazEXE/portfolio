# Moaaz Khamis — Portfolio

Personal portfolio website built with a dark, techy aesthetic.

## Stack

- Astro
- Tailwind CSS
- TypeScript

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

Vercel — connect your GitHub repo and deploy with zero config.
